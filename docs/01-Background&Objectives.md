# 课题内容

开发 Demo 实现头条首页的列表页面，通过列表页面开发提升和考察：

- 工具使用：Android Studio、Git、Github 等的使用
- 开发技能：Kotlin、ComposeUI、协程、数据库等
- 研发素养：技术文档撰写、代码规范风格考察、工程架构理解
- 业务理解：理解新闻应用的架构、核心业务流程

# 功能拆解

基础功能（必须）：

- 数据加载
- 卡片展示

进阶功能（可选）：

- 加载状态控制
- 下拉刷新和加载更多
- 数据库存储

加分点：

- 开发技能：Kotlin 协程、ComposeUI 等新技术栈实现 
- 研发素养：良好的技术文档、体现架构设计比如 MVI 、MVVM 等

# 作业提交

- 提交 github 项目
- 提交飞书技术文档
- 进度飞书文档：周报、日报

# 验收标准

- Github 项目（60%）
- 飞书技术文档（40%）
