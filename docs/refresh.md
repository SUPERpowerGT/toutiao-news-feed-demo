双写模式

Cache-Then-Network (CTN) 双写模式

```
打开 app
↓
立即显示缓存
↓
同时请求 /feed?cursor=
↓
如果后端返回比缓存新 → 覆盖 UI
↓
把返回的第一页写回本地缓存

```

 混合排序（Re-Ranking）

| 场景             | cursor 含义            | SQL 条件              | 目的                 |
| ---------------- | ---------------------- | --------------------- | -------------------- |
| **上滑加载更多** | 当前列表“最老的”时间戳 | publish_time < cursor | 加载更旧的数据       |
| **下拉刷新**     | 当前列表“最新的”时间戳 | publish_time > cursor | 查有没有更新的“更新” |
